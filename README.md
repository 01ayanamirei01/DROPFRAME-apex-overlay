DROPFRAME — оверлей-трекер Apex
Читает ранг, киллы, урон, место и киллфид с картинки экрана.
Как Valorant Tracker: никакой памяти игры, только кадр.

════════════════════════════════════
1. В браузере (чтение HUD)
════════════════════════════════════
Открой файл DROPFRAME-overlay.html в Chrome или Edge.
Нажми «Шарить окно Apex» и выбери окно игры.
Или «Прогнать демо-кадр» — проверка без игры.

════════════════════════════════════
2. В OBS (поверх стрима)
════════════════════════════════════
Источники → Браузер
- Локальный файл: DROPFRAME-overlay.html
- Ширина 1920, высота 1080
- В конце адреса допиши ?obs=1
  пример:  .../DROPFRAME-overlay.html?obs=1
- Custom CSS:
  body { background-color: rgba(0, 0, 0, 0) !important; margin: 0; overflow: hidden; }

Игра — отдельным источником Game Capture.
Оверлей кладётся сверху.

Чтобы оверлей сам читал киллы со экрана, держи HTML открытым
в обычном Chrome (шаринг окна) и захвати это окно в OBS,
либо вбивай ранг/ник руками в панели слева.

════════════════════════════════════
3. Что читает
════════════════════════════════════
Ранг, легенда, киллы, урон, место (#N), RP, строки киллфида.
